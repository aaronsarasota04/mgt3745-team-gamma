# DDR-005: Drafting ADR-002

## Task

Draft ADR-002 in `context/ARCHITECTURE.md` to describe how the current Phase 2
system differs from ADR-001 and clarify the proposed scope: Gemini role
suggestions are not implemented, student skills are request-scoped and not
persisted, and F2, F3, and F4 are deferred from this release. The ADR also
records authentication as a revisit trigger before accepting real student
skill data or opening the app to external students.
