# DDR-007: Updating the Architecture Diagram for ADR-002

## Task

Update the Mermaid architecture diagram in `context/ARCHITECTURE.md` to match
the approved ADR-002 and the current Phase 2 implementation. The diagram now
shows the static page served by the Worker, the `/api/roles` and `/api/gaps`
routes, request-scoped student skills, and D1's posting data. Gemini role
suggestions and persisted student skills are not shown because they are not
part of ADR-002 or the deployed code.

## Trust Boundary

Repository contents, including `context/ARCHITECTURE.md` and the implementation
files, were sent to GPT-6 Luna to compare the obsolete ADR-001 design with the
current ADR-002 scope and implementation. The author is accountable for
reviewing the diagram against the approved decision and code. No credentials,
real student data, dependencies, or executable code were returned.

## Verification Performed

- Visually compared the diagram with ADR-002's decision and revisit conditions.
- Ensured it is represented in the code also.

## Findings

- The revised diagram matches the current implementation: the browser calls
  `GET /api/roles` and `POST /api/gaps`; the Worker reads postings from D1; and
  student skills are used only for the current request.
- ADR-001's Gemini integration and saved student-skill table are not part of
  the approved current scope. F2, F3, and F4 remain deferred from this release.
- No code changes were required.
